FİNANSIM — KURULUM

Ücretsiz kişisel finans uygulaması. Sunucu/veritabanı gerektirmez.

Bilgisayarda hemen kullanmak:
- index.html dosyasını çift tıklayarak aç.
- Bazı tarayıcılar file:// altında yerel depolamayı farklı davranışlarla yönetebilir. En güvenilir kullanım HTTPS üzerinden yayınlamadır.

Ücretsiz telefon ve bilgisayar erişimi:
1. GitHub'da ücretsiz bir hesap aç.
2. Yeni bir PUBLIC repository (ör. finansim) oluştur. UYARI: kodun herkese açık olur, kişisel işlemlerin yayınlanmaz; bunlar tarayıcında saklanır. Asla JSON yedeğini repository'ye yükleme.
3. Bu klasörün içindeki index.html, manifest.webmanifest, service-worker.js ve üç icon dosyasını repository köküne yükle.
4. Settings → Pages → Deploy from a branch → main → /(root) → Save.
5. Yayınlanan https://KULLANICI.github.io/finansim/ adresini Safari'de aç.
6. Safari → Paylaş → Ana Ekrana Ekle. Bilgisayarda da aynı siteyi açabilirsin.

ÖNEMLİ: Telefon ve bilgisayar AYRI veriler tutar. Otomatik senkronizasyon yok.
Ayarlar → JSON yedek indir ile yedek al; diğer cihazda Ayarlar → Yedek yükle.
Yedekleme mevcut kayıtları değiştirir, birleştirme yapmaz.
Tarayıcı verileri temizlenirse yedeksiz işlemler kaybolabilir.

İlk değerler: aylık gelir 10.000 + 32.000 TL; yaşam 12.000 TL; beklenmedik gider 3.000 TL; telefon 800 TL; banka 10.000 TL; borç 10.000 TL; yatırım 250 USD.
Maaşlar/telefon otomatik işlem olarak işlenmez; para gerçekten geldiğinde veya harcandığında kaydet.
Kredi kartı ödemesi nakit ve kart borcunu azaltır, aylık yaşam giderine ikinci kez yazılmaz.
Yatırım tutarı USD olarak izlenir; otomatik canlı kur yoktur.
Bu sürüm tek banka hesabı ve kart borcunu destekler; hesaplar arası otomatik eşitleme bulunmaz.
